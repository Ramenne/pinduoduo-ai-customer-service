# 本地交互展示

在仓库根目录运行：

```bash
npm run demo
```

打开 http://127.0.0.1:4173 。需要第二个同时运行的窗口时，使用 `node demo/server.mjs 4174`。

账号 `demo`，口令 `demo-only`。无需 npm install、数据库或 API Key；需要 Node.js 20+。

这是独立重绘的交互原型，帮助理解产品流程。它与原始前端分别存放；登录只切换浏览器会话状态，页面不调用后台或模型。全部会话、订单、成员、任务及图表指标均为模拟，不作为业务成果。

建议展示顺序：经营概览 → 接待工作台 → 选择会话 → 人工接管 → 输入回复并模拟发送 → AI协作区 → 知识维护。顾客回复和内部补充分区显示，发送仅保存在当前页面。

重置演示清空本页模拟消息；刷新会清空内存中的交互记录，退出会移除本标签的演示登录状态。

页面采用浅色布局、侧栏导航、状态标签和内容卡片。演示不是原线上 UI 截图，不证明真实鉴权、LLM推理、消息收发或数据库迁移已经通过验收。
