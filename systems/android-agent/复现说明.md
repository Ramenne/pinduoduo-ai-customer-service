# OIN手机版：预热／每日维护

此包不是FF闲鱼后台的xianyu-mobile壳。Android原生助手在手机上执行闲鱼页面操作；控制面保存账号、设备绑定、任务及结果。

## 服务端在新电脑启动

安装Python 3.11+，在本目录执行：

```sh
python3 -m venv .venv
# Windows: .venv\Scripts\activate；macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python launch.py
```

默认开发SQLite会在runtime中创建并自动迁移，健康检查http://127.0.0.1:18080/healthz。代码自带schema.sql、schema.postgresql.sql及全部迁移，database下另有副本。账号通过原注册入口建立，设备要重新绑定，不复制生产用户和设备签名。

手机接入需要可信HTTPS地址。launch.py的https://localhost:18080只是开发的公开URL声明，不会自动生成TLS；请部署可信证书的反向代理，将公开HTTPS路径指向本地18080（支持WebSocket），并配置OIN_PUBLIC_BASE_URL。不要把裸HTTP健康检查当成手机已连接。

正式PostgreSQL部署可参考source/deploy/xianyu-selling/bootstrap.py及服务README，需独立oin_v01库、oin_v01_owner和oin_v01_app角色；数据库口令在新环境生成，不能复制旧生产密码。首次新库先执行bootstrap，再以运行角色启动；不要在旧库重跑创建脚本。

## Android源码构建

Android Studio导入source/apps/android-agent。需要JDK17、Gradle8.11.1、Android SDK35和Build Tools35.0.1，保持原AGP8.10.0配置。源码没有机器专属local.properties；由Android Studio生成SDK位置。

提供真实HTTPS服务地址后构建：

```sh
gradle -p source/apps/android-agent -PoinCloudBaseUrl=https://你的域名/oin assembleDebug
```

发布构建按原README设置签名；原发布私钥未随包交付，新签名不能保证覆盖已安装程序。默认输入法功能仍可关闭，无障碍需要在手机系统中授权。

original-apk下保留线上66版签名APK，其SHA256与线上metadata一致；它仍指向原服务。要连接自己部署的新服务，必须按新HTTPS地址重新构建。
