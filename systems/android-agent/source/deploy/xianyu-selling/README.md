## 原生手机任务中心基线（code39 / 0.12.1-v01）

## 使用路径与当前边界

1. 在网站注册/登录OIN账号，下载APK，在手机登录同一OIN账号并完成设备注册及权限设置；不是USB连接。当前未导入旧服务器账号或设备数据库，不声称完成数据迁移。
2. 在设备页进入“闲鱼上新与维护”，保存真实商品标题、描述、价格与图片。
3. 从手机实际页面读取精确节点，配置上新/编辑/擦亮/数据观察/回复流程；模板支持`{{title}}`、`{{description}}`、`{{price}}`、`{{reply}}`、`{{target}}`。不含猜测的闲鱼按钮选择器。
4. 不可逆步骤后至少配置页面与商品/会话两项实页校验。排队落盘，任务号稳定，未知结果停住并需人工对账，不自动重做。
5. 每日维护只允许擦亮/数据观察排期；离线期间错过的周期不集中补做。优化和回复由人给出内容/授权；不会模拟收藏、刷量、下单或删后重发。

未验证：手机安装、当前闲鱼页面节点与账号、真实发布/回复/擦亮、系统图片选择器路径。无真实素材、设备连接和实页配置时只能保持等待/失败/未知，不会伪报发布成功。`import_image`只导入相册，不能把它当成已经选图上传。
