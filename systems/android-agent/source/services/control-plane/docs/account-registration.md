# OIN 登录与注册更新 · 2026-10-15

版本：Android 54 / 0.17.4-v01；桌面候选 0.17.4-registration-20261015。

手机账号区及新版 WPF 桌面入口同时显示登录、注册。网页 /oin/login、/oin/register 同时提供两种入口。注册校验用户名、密码与确认密码，收到实际保存回执才显示成功；重复账号明确提示，网络结果不明确时提示先尝试登录，不自动重发注册。

手机、网页、新版桌面使用 POST /api/v1/accounts 注册，POST /api/v1/mobile/sessions 登录。后端已有 accounts/account_users 原子保存、加盐 PBKDF2 密码摘要、重复校验及注册审计。本次接通客户端，不改数据库结构。手机注册不重新绑定当前设备。

旧 WinForms Studio 保留 oin_studio PostgreSQL 账号库，注册入口不再因本机以前登录过而消失，新增独立确认表单并防止重复提交。旧账号未迁移到控制台账号库，两类账号暂不互通。历史 Studio 构建会嵌入连接配置和私钥，故本次旧 Studio 构建仅限本地受限保留，不作为公开下载交付；后续需将其存储接入改为服务端账号接口或独立受限配置。

验证：Android assembleRelease/lintRelease 通过；API29模拟器登录/注册入口、打开注册表单及必填校验通过。后端账号相关6项测试通过，其中新建服务实例后仍能登录同一SQLite数据库的账户；桌面真实API适配代码25项测试通过。WPF与旧Studio win-x64自包含构建通过。尚未验证Windows实际运行及手机注册真实HTTP全链；未新建生产测试账号。
