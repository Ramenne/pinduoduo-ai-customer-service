当前基线 e8588a7 / 生产0.1.17。只沿用本人既有工程权限；不创建中枢任务/编号或上传资料。

完成线：顾客/工作人员事件 → 共用指引与结构化业务决定 → 多问题/事实持久状态 → 原待补、草稿、接管、发送服务 → 真正执行结果回写 → 原知识候选审核。

约束：不新增发送通道、消息账、知识权威或平台轮询；模型不授予发送权限；人工模式发送须当前工作人员明确授权；一个问题结束不关闭其他问题；临时库存不进长期知识；旧消息/代际保护、未知结果不重发不变。

实现：现有会话控制记录增加可空 harness_json，保存逐问题状态、来源事实、最近决定与执行标识；工作区继续负责人工批次和待补。自动/内部/草稿使用同一业务Contract和程序必带指引，不增额外分类模型调用。自然语言仍是人工唯一输入。

验证：多问题部分处理、混合事实与已回复、未知/纠正/新规格、跨入口语义、已解决问题追问、发送授权/新消息冲突/未知发送/重启、知识增量去重。先隔离测试/真实模型合成案例，后发布检查，不主动向真实顾客发送测试消息。
