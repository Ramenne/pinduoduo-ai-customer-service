# 03-闲鱼管理系统复现

版本依据见VERSION.json。源码、数据库结构及生产环境观察到的Python依赖已放入本目录；依赖安装需要联网。这里不复用生产登录态。

## 原生启动（Windows / macOS / Linux）

先安装Python 3.11或3.12、Node 20+、MySQL 8.0、Redis 7，启动本机MySQL和Redis。

在本目录打开终端：

```sh
python3 -m venv .venv
# Windows执行 .venv\Scripts\activate；macOS/Linux执行 source .venv/bin/activate
python reproduce.py install
python reproduce.py init-env
```

编辑刚生成的runtime.env，把本机MySQL用户名、密码、端口和Redis连接写好。默认创建专用 *_local 库，不读取原生产库。

```sh
python reproduce.py init-db
python reproduce.py backend
```

另开同一目录终端并激活同一虚拟环境，分别运行：

```sh
python reproduce.py browser-install
python reproduce.py websocket
python reproduce.py scheduler
python reproduce.py frontend
```

最后四条长运行命令各占一个终端；browser-install只在首次或更换浏览器版本时执行。Linux可能还需安装Playwright系统依赖，见原Dockerfile的--with-deps步骤。

网页：http://127.0.0.1:9000 。后端健康检查：http://127.0.0.1:8089/health 。首次启动后端沿原逻辑补字典、角色与管理员。闲鱼原初始化逻辑的初始管理员为admin/admin123；首次本地登录后立即修改，勿把此默认账号直接公开到互联网。

本地 *_local 空库的辅助脚本会设置 login_captcha_enabled=false，以便首次登录不依赖原验证码供应商；仅用于本地复现，对外部署前需自行配置验证码。该设置不修改原源码和任何线上库。

空库不含店铺、模型密钥、邮件账号、商品、订单和聊天。登录界面可用不等于平台账号已授权；店铺重新登录及模型、邮件等资源需自行配置。不上线真实店铺即可检查页面、账号及基础服务。

## 数据库结构

database/schema.sql为2026-10-23从实际部署库导出的结构，不含任何业务行。schema-info.json有表清单及摘要。程序自动初始化补充必需字典/角色/配置；不需要复制旧管理员密码哈希。

## 容器与构建

source内保留原Dockerfile和docker-compose.yml，属于原工程配置。原配置的默认端口/容器名可能与本机其他实例冲突，应先检查并改为本地专用值；本次实际检查以原生步骤为主，未宣称Docker全平台已跑通。前端源码和匹配构建产物都保留，npm run build可重建。
